Text sources (read, not stored as images):
- SR-71A-1 flight manual (the archive.org item above, the OCR text of vols. 01-03): section I "Dimensions" (length 107.4 ft,
  height 18.5 ft, span 55.6 ft, wing area 1605 ft2, tread 16.67 ft), gross / zero-fuel weights, J58 thrust (34,000 lb
  uninstalled SL static, min AB ~85 % SL / ~55 % at high altitude, AB fill time 3 s SL / 7 s at altitude, bypass at CIT
  85-115 C = Mach 1.8-2.0), fig. 1-4 military thrust; section II normal procedures (210 KIAS take-off, 8-10 deg take-off
  attitude, gear up by 300 KEAS, 400 KEAS climb to Mach 0.9, refuelling at 25,000 ft, 450 KEAS supersonic climb, 175 KIAS
  final, 155 KIAS touchdown +1 kt per 1,000 lb over 10,000, drag chute limit 210 KIAS); section V limits (Mach 3.2 design,
  3.17 max scheduled cruise, 3.3 if CIT <= 427 C, 310 KEAS minimum supersonic, 450 KEAS climb).
- Mach 0.9 at 30,000 ft = 324 KEAS / 347 KIAS (SR-71A-1 sec. II) - used as an atmosphere check in the bench.
